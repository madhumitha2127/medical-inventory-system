## 📌 Overview

A medical inventory management application designed to organise medical stock information and simplify inventory-related operations.

## ✨ Features

- 📦 Medical stock management
- ⏰ Expiry date tracking
- 🧾 Billing management
- 📱 QR code functionality
- 📊 Inventory analytics

## 🛠️ Technologies

- **Backend:** Python
- **Frontend:** HTML
- **Database:** Refer to the database configuration in the source code

## 📁 Project Structure

```text
medical-inventory-system/
│
├── static/
├── templates/
├── app.py
├── database.py
├── requirements.txt
└── README.md
```

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/madhumitha2127/medical-inventory-system.git
```

2. Navigate into the folder:

```bash
cd medical-inventory-system
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Follow the application startup instructions in `app.py`.

## 🎯 Objective

To simplify medical inventory operations through organised stock tracking, expiry monitoring and billing support.
