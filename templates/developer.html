Medical Inventory System (MediTrack Pro)

A comprehensive, high-security enterprise pharmacy solution designed to optimize medicine stocking, automate retail billing workflows, centralize supplier registers, and deliver responsive analytics charts. Fully optimized for production-grade speed, secure dynamic user environments, and zero-leak session handling.

Flask (Python) SQLite3 (Database Engine) Glassmorphism UI Framework ReportLab (Dynamic PDF compilation) Chart.js (Responsive Analytics) Secure Session Auth (scrypt Password Hashing) Dynamic User Provisioning

🛠️ Technical Architecture & Highlights

🔒 Hardened Security Layer

Protected by cryptographic scrypt hashing for database user profiles and absolute session isolation. Implements full anti-CSRF protection across all transaction POST endpoints, strict file type filtering on uploads, and safe DOM processing policies to mitigate XSS.

🧾 Dynamic Retail Billing Counters

A fully integrated billing interface allowing users to stage stock purchases. It includes built-in warning checks for available quantities, automated batch deductions on checkout, and QR invoice generation using base64 rendering.

📊 Dynamic HSL Charting & Analytics

Utilizes custom CSS variables to feed themed palettes to a responsive HTML Canvas chart layout. Feeds sales data from the SQLite layer to Chart.js elements, showing detailed daily revenue metrics and inventory counts.

📃 ReportLab PDF Engine

Leverages native Python canvas manipulation to compile and format highly professional physical documents in real-time. Features multi-page table safety calculations and themed invoice styling ready for physical thermal printing.
